# HTTP vs HTTPS

## 📖 Introduction

This project explains the difference between **HTTP (HyperText Transfer Protocol)** and **HTTPS (HyperText Transfer Protocol Secure)**.

HTTP is used for communication between a browser and a server, while HTTPS provides a more secure form of communication by encrypting the data transferred between them.

---

## 🌐 HTTP

**HTTP** stands for **HyperText Transfer Protocol**.

It provides a set of rules that allows a browser and server to communicate with each other.

### Key Points

- HTTP is used for communication between a browser and a server.
- HTTP methods such as `GET` and `PATCH` can be used to send requests to a server.
- HTTP does not provide encrypted communication.
- Data transferred through HTTP may be viewed or altered by attackers.
- HTTP is therefore not suitable for transferring sensitive information securely.
